# CentauroHybridMPC package

Collection of Centauro-specific MPC and MPC cluster implementations for RL-augmented MPC within the [IBRIDO](https://github.com/AndrePatri/IBRIDO) framework. Used by [AugMPC](https://github.com/AndrePatri/AugMPC).

In particular, this repository hosts:
- MPC configurations for the Centauro (full-body legged/hybrid locomotion, etc...)
- MPC cluster implementations based on [MPCHive](https://github.com/AndrePatri/MPCHive)
- Joint impedance configurations
- Helper launchers and configurations to help run the robots within [xbot2_mujoco](https://github.com/AndrePatri/xbot2_mujoco)
- [MPCViz](https://github.com/AndrePatri/MPCViz) robot-specific configuration and helps to debug and visualize MPC plans
